关于 AI NEWS

一个自动采集、评分、排序 AI 行业资讯的独立站点。

这是什么

AI NEWS 是一个全自动的 AI 行业日报系统。每天从 30+ 个来源（含 AIHOT 的 18 个官方 / 媒体 RSS）抓取 AI 相关资讯，经过滤精炼后，由 LLM 对每条新闻评分排序，最终生成结构化的日报。

它既是个人网站的组成部分（通过 API 供前端调用），也是一个可独立访问的网站。

工作流程

📡 采集 — 从 GitHub / HF / arXiv / TechCrunch / HN / 36氪 等来源抓取
↓
🔍 精炼 — 过滤噪音、去重、时效性检查
↓
📊 评分 — LLM 对每条新闻打 0-100 分（无 API 时回退到关键词评分）
↓
🔥 热门 — 提取 Top 6 组成"今日热门"板块
↓
🌐 发布 — 生成 JSON API + 独立网站

数据来源

RSS 信源来自 AIHOT 的信源清单（sources_config.json），按层级设置精选门槛：T1 官方一手 ≥ 60，T2 媒体 / 个人 ≥ 76。

API 接口

  • GET /api/v1/ai_news/news — 结构化日报 JSON
  • GET /api/v1/ai_news/news?date=YYYY-MM-DD — 按日期查询
  • GET /api/v1/ai_news/hot — 热门条目 JSON（按评分排序）
  • GET /api/v1/ai_news/dates — 可用日期列表
  • GET /api/v1/ai_news/cards — HTML 卡片
  • GET /api/v1/ai_news/sources — 信源采集状态
  • GET /api/v1/ai_news/search?q= — 搜索历史条目

技术栈

  • Python + FastAPI — 后端 API 与网站
  • Jinja2 — SSR 模板渲染
  • OpenAI 兼容 API — LLM 评分（DeepSeek / Qwen / GLM 等）
  • 关键词启发式 — 无 LLM 时的回退评分
